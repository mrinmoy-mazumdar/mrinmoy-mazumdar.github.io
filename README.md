## Publishing

In GitHub:
1. Open **Settings → Pages**
2. Under **Build and deployment**, choose **Deploy from a branch**
3. Select the `main` branch and `/ (root)`
4. Save
5. GitHub will provide the live Pages URL

Replace the portfolio PDF and placeholder project images with work you are permitted to publish. Do not upload confidential employer/client material.
